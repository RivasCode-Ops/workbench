# 40-DIAGNOSTICO

Esta etapa serve para investigar falhas e causas quando o problema nao esta claro.

Use quando:
- o contexto desta fase estiver ativo
- houver necessidade de saida objetiva e rastreavel
- o proximo passo depender de uma decisao estruturada

Entregavel desta etapa:
hipotese de causa raiz e plano objetivo de validacao/correcao.
