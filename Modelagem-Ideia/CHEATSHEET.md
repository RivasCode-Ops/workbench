# Modelagem de Ideia — Cola

```
Ideia solta (texto, recorte, reportagem)  →  MI-SESSAO-UNICA  ou  MI00→MI04
```

| Passo | Arquivo |
|-------|---------|
| Colar material | `MI00` ou `MI-SESSAO-UNICA` |
| Extrair negócio | `MI01` |
| **Qual modelo + explicação** | `MI02` |
| Preencher quadro | `MI03` |
| Fechar + próximos passos | `MI04` |

**Modelos:** `MODELOS-CATALOGO` (M1 Canvas … M9 impacto)  
**Voz:** `PERSONALIDADE-CONSULTOR` (Sebrae sênior)  
**Exemplo:** `EXEMPLO-SAIDA`

**Depois:** `Projeto Novo/001` ou `000` se for construir sistema

**Gate:** `ESTRUTURAR` | `COMPLEMENTAR` | `REFOCAR` | `ARQUIVAR`
