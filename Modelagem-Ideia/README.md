# Modelagem de Ideia — Do rascunho ao modelo de negócio

Você tem **ideia solta** (texto, recorte, reportagem, anotações, áudio transcrito)?  
Esta pasta transforma em **modelo estruturado** com orientação de **consultor sênior (estilo Sebrae)**.

---

## O que esta pasta faz

1. **Lê** o conteúdo bruto (qualquer formato)
2. **Extrai** problema, cliente, dinheiro, concorrência
3. **Indica** qual modelo de negócio usar (Canvas, Lean, Plano Sebrae, SaaS…)
4. **Explica** para você o que é o modelo e como usar
5. **Preenche** o modelo com estrutura profissional
6. **Orienta** próximos passos (validar, formalizar, ou ir para kit técnico)

**Não faz:** código, arquitetura, PR, raio-X técnico.

---

## Fluxo

```
MI00 (cole o material bruto)
   ↓
MI01 (extrai insights e lacunas)
   ↓
MI02 (escolhe o modelo + explica por quê)  ← você entende O QUE será
   ↓
MI03 (preenche o modelo completo)
   ↓
MI04 (orientação final + roteamento)
```

**Atalho:** `MI-SESSAO-UNICA.md` — tudo em um prompt (material pequeno).

---

## Quando usar

| Situação | Use |
|----------|-----|
| Ideia só na cabeça / WhatsApp / papel | MI00 → MI04 |
| Reportagem inspirou um negócio | MI00 + citar fonte |
| Não sabe se é SaaS, loja ou serviço | MI02 |
| Já estruturou e vai codar | `Projeto Novo/000` |
