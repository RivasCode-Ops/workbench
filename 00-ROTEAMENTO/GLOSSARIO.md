# Glossário

| Sigla | Significado |
|-------|-------------|
| **D00–D13** | Coding diário (domínio 20) |
| **000–12** | Agentes de produto/planejamento (domínio 20) |
| **001, 002** | Descoberta e arquitetura |
| **14, 13** | Triagem e retrofit legado |
| **MI00–MI04** | Modelagem de ideia (domínio 10) |
| **B00–B09** | Guardião PR (domínio 30) |
| **QA00–QA04** | Auditoria app (domínio 30) |
| **RX01, RX02** | Raio-X (domínio 40) |
| **R00–R05** | Correção rápida (domínio 50) |
| **Gate** | Decisão de continuar ou parar (`APROVAR`, `MERGE_OK`, …) |
| **Prometido** | Lista do usuário do que a entrega deveria fazer (auditoria app) |
| **P0–P3** | Prioridade (bloqueante → cosmético) |
| **N/T** | Não testado |
| **F/H/?** | Fato / Hipótese / Lacuna (modelagem) |
| **BLOCKER** | Achado que impede merge (Guardião) |
| **Contrato** | Bloco Objetivo/Entrada/Saída no topo do prompt |

## Domínios vs pastas legadas

| Domínio | Pasta legada (ainda válida) |
|---------|----------------------------|
| 10 | `Modelagem-Ideia/` |
| 20 | `Projeto Novo/` |
| 30 | `Guardiao-PR/`, `Auditoria-App/` |
| 40 | `Raio-X-Projeto/` |
| 50 | `Correcao-Rapida/` |
| 90 | `Pojeto Antigo/` |
