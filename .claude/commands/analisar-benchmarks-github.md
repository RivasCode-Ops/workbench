# /analisar-benchmarks-github

Objetivo:
Analisar projetos publicos no GitHub similares a demanda atual (priorizando os com mais estrelas) para extrair diferenciais, boas praticas reaproveitaveis e riscos de adocao.

Entrada esperada:
- descricao do projeto atual (tipo, stack, objetivo)
- contexto de uso principal
- publico-alvo
- restricoes tecnicas e de produto

Tarefas:
1. Buscar projetos similares por tipo de produto e stack.
2. Priorizar projetos com sinais de maturidade (estrelas, documentacao, releases, atividade).
3. Para cada projeto selecionado, levantar:
   - nome, link e estrelas aproximadas
   - diferenciais de produto/UX/features/arquitetura
   - praticas que valem copiar/adaptar
   - riscos e itens nao recomendados para adocao
4. Consolidar aprendizados em sugestoes aplicaveis ao projeto atual.
5. Propor 3 a 5 proximos passos priorizados.

Regras:
- Nao copiar codigo literalmente.
- Priorizar conceitos, padroes e abordagens.
- Ao sugerir implementacao tecnica, descrever em alto nivel para a stack atual.
