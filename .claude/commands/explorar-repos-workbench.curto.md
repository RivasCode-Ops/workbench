# /explorar-repos-workbench-curto

Objetivo:
Mapear rapidamente repositorios do GitHub que possam melhorar o `workbench` em metodo, documentacao e automacao.

Entrada:
- contexto atual do `workbench`
- tipo de melhoria buscada (workflow, docs, handoff, IA, automacao)

Instrucoes:
1. Buscar repositorios relevantes e maduros (priorizar estrelas e qualidade da documentacao).
2. Selecionar os mais aderentes ao `workbench`.
3. Para cada repositorio, trazer:
   - nome, link, estrelas aproximadas
   - principal aprendizado
   - o que adaptar no `workbench`
   - risco de adocao
4. Consolidar recomendacoes praticas e priorizadas.

Saida:
## Top repositorios
- Nome / Link / Estrelas / Aprendizado principal

## O que adaptar no workbench
- arquivos novos
- ajustes de fluxo/documentacao
- automacoes IA/dev tools

## Plano rapido (3-5 acoes)
- [acao] -> [beneficio]
