QUERO QUE VOCE ATUE COMO ANALISTA DE PROJETOS GITHUB

Contexto:
Estou desenvolvendo um projeto com estas caracteristicas:
- Nome interno: Quadro Negro
- Tipo: app web de planejamento visual / kanban / produtividade
- Stack principal: Next.js + TypeScript + Prisma + Postgres
- Objetivo: ajudar o usuario a organizar tarefas, prioridades e rotina

Tarefa principal:
Quero que voce analise projetos publicos no GitHub com caracteristicas semelhantes (principalmente os que tem mais estrelas) e identifique o que eles fazem de diferente ou melhor, para que possamos aprender e incorporar ideias.

Regras para sua analise:
1. Considere sempre:
   - tipo de produto (kanban, task manager, planner, dashboard)
   - stack (quando for similar a minha)
   - nivel de maturidade (estrelas, documentacao, issues, releases)

2. Para cada projeto analisado, quero que voce extraia:
   - Nome do projeto e link no GitHub
   - Numero aproximado de estrelas
   - Principais diferenciais (produto, UX, features, arquitetura)
   - Boas praticas que podemos copiar ou adaptar
   - Riscos ou coisas que nao vale a pena trazer

3. Foco especial em:
   - funcionalidades que eu ainda nao tenho ou nao pensei
   - abordagens de UX/UI que podem melhorar muito a experiencia
   - padroes de arquitetura e organizacao de codigo que facilitem manutencao
   - formas de usar IA (se houver) que facam sentido para o meu contexto

4. Nao copie codigo literalmente.
   - Quero ideias, padroes, conceitos e abordagens, nao copiar e colar trechos de codigo.
   - Quando falar de algo tecnico, descreva em alto nivel como poderiamos implementar na minha stack.
