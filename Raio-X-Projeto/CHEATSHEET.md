```
Estrutura pronta? Precisa trabalhar?  →  RX01 (ou RX02 rápido)
```

| Situação | Arquivo |
|----------|---------|
| Análise completa | `RX01-RAIO-X-COMPLETO` |
| Reunião / 15 min | `RX02-RAIO-X-RAPIDO` |
| Formato dos quadros | `TEMPLATE-SAIDA` |
| Não sabe qual | `000-ORQUESTRADOR` |
